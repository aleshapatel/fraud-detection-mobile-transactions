# Fraud Detection in Mobile Financial Transactions

## Project Overview
This project focuses on detecting fraudulent mobile financial transactions using Machine Learning techniques. It analyses transaction data and applies different classification algorithms to identify potentially fraudulent activities.

## Objectives
- Analyse mobile financial transaction data.
- Identify patterns associated with fraudulent transactions.
- Train and compare multiple Machine Learning models.
- Help distinguish between legitimate and fraudulent transactions.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Streamlit
- XGBoost
- Power BI

## Machine Learning Algorithms
The project explores the following algorithms:
- Logistic Regression
- Decision Tree
- Random Forest
- AdaBoost
- XGBoost

## Project Features
- Data analysis and preprocessing.
- Machine Learning model training.
- Fraud prediction.
- Interactive Streamlit application.
- Power BI dashboard for data visualisation.

## Project Structure
The repository contains the project notebook, Python scripts, application files, dashboard and project documentation.

## How to Run
1. Clone or download this repository.
2. Install the required Python packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```

*Note: Check the actual application filename in the repository. Replace `app.py` in the command if your Streamlit file has a different name.*
